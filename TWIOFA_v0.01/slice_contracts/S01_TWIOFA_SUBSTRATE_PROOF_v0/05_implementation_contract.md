# Implementation Contract

This slice authorizes only a future narrow proof implementation.

The implementation may create a single-screen material prototype after this contract is accepted.

The implementation must preserve:

- substrate-proof-first target
- one active chunk first
- material consequence first
- no LBM
- no infinite world
- no general engine
- no full ECS
- no tile-grid presentation as final direction

The future implementation should be judged by player-visible material consequence, not by how many abstractions exist.
