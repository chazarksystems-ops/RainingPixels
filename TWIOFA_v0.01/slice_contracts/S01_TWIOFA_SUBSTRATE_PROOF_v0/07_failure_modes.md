# Failure Modes

This slice fails if:

- it becomes a generic engine project
- it becomes a tile/grid tactics prototype
- material consequence is only described in UI text
- ants are invisible or irrelevant
- collapse/water/moisture do not affect decisions
- the prototype hides the substrate behind menus
- scope expands into procedural yard, full ECS, save/load, or streaming
- LBM/full CFD re-enters the v0 path
- visual readability is treated as optional polish
