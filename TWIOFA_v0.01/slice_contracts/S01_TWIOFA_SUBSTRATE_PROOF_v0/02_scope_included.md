# Included Scope

This slice includes:

- one active material chunk / one-screen scene
- packed `u32` cell-state rules as design contract
- air, dry dirt, wet dirt, loose soil, water, stone/root blocker
- simple digging
- simple visible ants
- simple route consequence
- moisture/wetting behavior
- collapse/tunnel liability behavior
- rough but continuous material readability
- world-click visible execution

It may use rough prototype visuals as long as it preserves the material-continuity direction.
