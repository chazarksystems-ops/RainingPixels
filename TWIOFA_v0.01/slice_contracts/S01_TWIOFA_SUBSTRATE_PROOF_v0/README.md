# S01_TWIOFA_SUBSTRATE_PROOF_v0

## Purpose

This is the parent slice for the first playable proof.

The slice must define the smallest believable ant-scale living-material world that can answer whether TWIOFA's core interaction is worth building around.

## Core Question

Can a player click/order ants in a reactive material yard, dig through material, see water/moisture/collapse change terrain, and feel that tunnel geometry itself is gameplay?
