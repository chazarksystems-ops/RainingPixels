# Slice Goal

Prove TWIOFA's substrate-first game premise through a narrow, playable material-interaction slice.

The slice should not prove all of TWIOFA. It should prove that the heart of the game exists:

- ants visibly act in a material world
- digging changes terrain
- water/moisture changes soil
- collapse can alter routes
- player sees consequence directly

If this slice does not feel promising, broad implementation should stop or be redirected.
