# Licensing Intent

This document records project intent only. It is not a final legal license file.

## Current Status

TWIOFA v0.01 is a documentation-first foundation repo. It is not yet a public release and contains no gameplay implementation code.

## Current Intent

If TWIOFA moves beyond personal/internal use, the preferred direction is open-source/community-first. The favored future license direction is GNU GPL-style reciprocity for the playable codebase, with strong support for community forks, homebrew variants, and shared experimentation.

## Not Yet Final

Do not add a formal `LICENSE` file unless Chaz explicitly approves the license choice at repo/release time.

## Why This Exists

This file prevents accidental assumptions by future agents. The absence of a final license file is intentional at this stage; the repo is currently a design/spec foundation.
