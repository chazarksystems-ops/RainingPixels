# Accepted Locks

## Current active target

```text
TWIOFA_SUBSTRATE_PROOF_v0
```

## Development lock

TWIOFA is currently in:

```text
documentation-first repo foundation
+
substrate-proof slice definition
```

It is not yet in broad code implementation.

## Core build lock

The first real playable proof is:

```text
one active material chunk
visible ant-scale material consequence
digging
water/moisture
collapse/tunnel liability
minimal ants
route consequences
```

## Runtime lock

The active runtime direction is:

```text
Rust + WGSL/WebGPU-style GPU packed-cell cellular material simulation
```

## Data lock

Cell state is one packed `u32`:

```text
0..7   material_id
8..15  local_flags
16..23 material_scalar_0
24..31 aux_0
```

For v0:

```text
material_scalar_0 = moisture/cohesion
aux_0 = scent
```

## Simulation lock

Use:

```text
cellular automata gravity / flow
capillary moisture diffusion
collapse/cohesion rules
minimal ant interaction
```

Reject for v0:

```text
LBM
full CFD
generic engine-first architecture
full ECS before proof
infinite world streaming before proof
flat tile/grid game feel
```

## Visual lock

The prototype must not present as a square tile board.

It must read as a continuous living material substrate with visible state changes.
